# 系统职责边界草稿

状态：大层次职责已确认；本文保留边界摘要，现行接口与状态权威见 ARCHITECTURE、API、EXECUTION、STATE-MACHINES。没有实现或运行验证。

| 层次 | 已确认职责 | 后续规范必须落实 |
|---|---|---|
| Vue 3 / Vue Flow | 画布编辑、配置、调试及运行展示 | 平台 DSL 与布局分离、变量映射、服务端校验与错误定位 |
| Go 平台服务 | 身份权限、应用与版本、发布审核、路由协调、请求/任务管理、文件与事件接口 | 业务状态权威、请求幂等、配额、执行授权、事件接收、SSE 恢复及审计 |
| Python 执行 worker | LangGraph 整图执行、DeepAgents 自主节点及子应用适配 | 固定制品加载、检查点、节点事件、取消/超时/审批恢复，以及与 Go 的状态协调 |
| 脚本执行服务 | 受限环境中的用户 Python 工具 | 固定依赖、输入输出与文件授权、资源/网络策略、生命周期和清理 |
| 离线训练环境 | 数据处理、LoRA 实验、留出评测、模型产物记录 | 数据与模型来源、可复现 manifest、训练与推理隔离，以及管理员登记 |

Go 与 Python 不得各自形成互相冲突的用户可见运行真相，具体业务状态、执行检查点和事件的权威关系需要在执行协议中明确。异步队列是投递和调度设施，不能自动提供用户级取消、恢复或业务成功的保证。

用户上传的脚本不在 Go API 或 Python Agent 主进程中直接执行。脚本工具输出属于不可信来源，仍需按声明类型、大小和文件访问范围校验。

平台运行版本与训练实验产物分别记录；调用某个模型服务端点，不意味着该外部服务权重天然不可变。模型配置版本、可得的模型标识和已验证的行为边界需要准确记录。
