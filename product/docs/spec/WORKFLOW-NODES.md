# 首版工作流节点目录

状态：节点集合已确认。本文为目录摘要；类型、输入输出、校验、分支/汇合与恢复的现行规格见 WORKFLOW-SPEC、EXECUTION 及 contracts/workflow.schema.json，尚未执行节点测试。

| 节点 | 确认的用途 | 详细方案须明确 |
|---|---|---|
| 开始 | 接收本次任务输入与授权附件 | 输入声明、附件引用、缺失字段与校验 |
| 结束 | 交付任务结果及产物 | 输出映射、结果有效性、成功或部分失败状态 |
| 模型 | 一次生成或分类 | 模型配置、结构化输出、超时、重试与降级 |
| Agent | 自主调用工具或委派专家 | 上下文、允许能力、循环预算、停止与结果验收 |
| 脚本工具 | 执行固定版本 Python 工具 | 输入输出、运行环境、文件授权、限额、日志与取消 |
| 调用应用 | 委派给固定版本子应用 | 数据映射、鉴权、调用链、预算、命名空间与错误 |
| 知识检索 | 按权限检索组织资料并返回出处 | 文档状态、过滤、分段、排序、引用与删除失效 |
| 条件分支 | 根据已有结果选择后续步骤 | 条件表达能力、类型、互斥与默认分支 |
| 并行汇合 | 协调独立分支并合并结果 | 激活分支、跳过、失败、取消与汇合策略 |
| 人工审批 | 运行中暂停并确认具体操作 | 审批对象、角色、参数绑定、有效期、恢复和拒绝 |

首周只实现销售分析纵向切片所需节点，不将十类节点全部作为第一周完成标准。
