# 用户流程与界面验收

普通业务人员通过画布和配置面板创作，不要求写 DSL、JSON Pointer 或部署配置。脚本上传是可选高级能力；业务人员可直接选择已审核工具，不能因支持脚本而把所有创作步骤变成写代码。

## 1. 信息结构

- **对话**：提交需求/附件，查看处理应用、澄清、候选选择、运行进度、结果和审批。
- **应用目录**：当前有权使用的已发布应用；用途、限制、输入输出和示例，不展示他人的任务数据。
- **创作台**：我的应用、画布、工具选择、配置、测试、提交审核及历史版本。
- **个人数据**：个人记忆候选/确认/修改/删除、文件与会话删除状态。
- **管理台**：用户/权限、模型目的地、工具构建、审核、配额、元数据故障与受权诊断。

按角色隐藏不相关入口；隐藏不能代替后端鉴权。桌面画布首版优先，手机支持对话/审批/查看结果，不承诺完整小屏画布编辑。

## 2. 创作到发布

从空白或销售模板创建→拖入节点→表单选择固定模型/工具/子应用→变量选择器显示来源与类型→检查连线→填能力卡→运行测试案例→提交审核。测试界面以节点状态、输入输出摘要和可操作错误定位，不要求业务用户读 Python traceback。

变量选择器只列该节点当前路径合法可用字段；分支值在 join 后按来源区分。节点错误跳转到对应面板与字段；无环/跨区域/类型错误解释“哪里不能连接、怎样修正”，不能只显示 `422`。

草稿显示保存 revision、冲突提示与重载/保留本地副本，不能无声覆盖别人修改。发布界面展示内容摘要、模型数据去向、工具联网/写权限、固定子版本和测试报告。审核后修改需要新提交。

## 3. 请求到结果

输入后先展示“正在选择应用”；歧义给有限候选及差别，缺信息则在原请求下提问。运行时显示处理应用/版本、当前节点、等待原因、取消入口；并行子任务折叠展示。

结果包含摘要、已验证统计附件、报告下载和引用；部分产物标记为未完成运行产物，不呈现为最终成功。脚本失败给缺列/行号或安全的修复建议；敏感堆栈仅受授权诊断查看。

同会话新普通任务展示队列和可取消操作；等待澄清/审批的控制回复进入对应待办，不排到队尾。过期回复提示已过期，并允许用户明确新建任务，不能偷偷复活旧任务。

## 4. 审批与数据控制

审批显示真实目标、发送/修改内容、关键参数、涉及资料和目的地，默认不选批准。点击后显示实际状态，重复点击幂等；原操作参数变化时要求重新确认。取消中显示“正在停止”，不能立即显示“全部操作已撤销”。

记忆候选显示来源和保存范围，用户可以拒绝；默认不批量全选。删除显示立即停止访问与物理清理/备份期限的区别。诊断授权选运行、对象范围和到期时间，可撤销，不捆绑训练授权。

## 5. HCI 验证

让未参与开发者完成三项任务：改销售模板的报告要求；处理一次缺列输入；判断一个需要审批的外部发送是否正确。记录完成率、耗时、回退、求助、误点击和对状态的复述。

若用户以为“发布共享”会公开个人文件、以为“取消中”已撤回发送、或不能识别哪份数据送往外部模型，视为界面失败，即使 API 行为正确也不通过。修复后用未见任务重测，不只换提示文案自评。
