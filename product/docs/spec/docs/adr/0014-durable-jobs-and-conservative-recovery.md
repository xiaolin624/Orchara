# 持久任务由平台管理，失联后先保守恢复

状态：已纳入当前开发基线；运行/故障验证尚未执行。

平台使用 PostgreSQL 保存任务、租约与业务事件，Python 经 Go 内部 API 领取，不共享 Go 任务库的私有 Redis 协议。这样减少两语言之间的隐式耦合，代价是需要实现明确的领取、配额和交接事务。LangGraph 原生 checkpoint 不验证平台租约，首版失联后先挂起，确认旧执行单元、沙箱及数据库会话已退出后才恢复，牺牲自动恢复速度来避免无围栏的双执行。需要自动接管时，必须先通过所有 checkpoint 写路径的原子围栏实验；不能仅靠发放新 token 宣称旧写已失效。
