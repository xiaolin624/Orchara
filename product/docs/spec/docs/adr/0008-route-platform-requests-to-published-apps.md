# 统一入口匹配已发布应用

用户选择直接向平台提出需求，由平台匹配已发布 Agent 应用，未采用先由用户选择应用的方案。因此平台需要应用路由层，并将发布内容与匹配目录保持一致。路由受已确认的应用使用权限约束。会话切换、歧义选择、单次需求的调用范围和具体匹配方法尚未确定，不能默认为无条件跨应用共享全部上下文或自主调用任意应用。

后续确认：同一平台会话可跨运行切换应用并展示处理者，交接必要信息而非全部内部数据。明确单一匹配自动使用，多个合适候选让用户选择，无匹配或信息不足则澄清。一次需求确定一个主应用负责协作与交付。发布必须提供经确认、审核的用途说明，作为匹配依据；具体算法与阈值后续用测试集验证。
