# 企业内部 Agent 创作与运行平台

状态：Q1–Q46已确认，包含产品边界、记忆接入和分层评测策略。实现细节与默认参数见README所列规格；设计访谈已闭合，尚未实现或实跑。

## 已确认的定位

服务单个企业内的多个用户，支持私有化部署。普通业务人员通过工作流画布创建可复用的 Agent 应用，保存定义，按需运行。可持续创建应用，容量由资源与配额确定，不承诺无限存储或无限同时运行。

首期目标是形成可检查的 AI 应用工程成果；开源传播目标独立于功能验收。第一周交付一个可验收的端到端纵向切片，完整工程分阶段推进。

## 已确认的核心能力边界

- 画布描述外层流程的步骤与分支。
- Agent 节点在步骤内部自主选择工具并按需委派专家。
- 允许上传 Python 脚本，作为声明结构化输入、输出与生成文件的工具使用；平台负责调度和运行管理。
- 脚本默认仅访问本次授权输入与独立工作目录；联网、企业系统与凭据须显式授权。
- 脚本执行有时间、内存和输出大小限制；采用私有 OpenSandbox + gVisor/runsc，参数建议见 OPERATIONS。
- 发布形成固定版本。运行绑定启动时所选的应用和脚本版本，作者后续修改不会替换正在运行的配置。
- 使用入口为 Web 对话与附件上传；平台会话可包含多个请求与应用运行。先形成平台请求，完成匹配与必要信息补充后才创建绑定版本的应用运行；澄清答复继续同一请求。
- 权限包含管理员、创作者和使用者；同一人可兼任。组织共享应用与脚本工具需管理员审核，个人草稿可在受限环境调试。
- 共享应用不自动共享使用者的会话、上传文件与个人记忆；作者也不因作者身份获得这些内容的读取权限。组织资料另行授权。
- 外层工作流为有向无环图，支持条件分支和并行汇合，不允许任意回边。Agent 节点内部自主循环有轮数、时间和费用预算限制。
- 用户直接向平台提出需求，平台在其有权使用的已发布应用中匹配处理者。明确单一匹配自动进入，多个适合候选供用户选择，无匹配或信息不足则澄清。
- 同一平台会话可跨运行切换应用，展示每次处理者，并明确交接必要信息；内部历史、文件和长期记忆不因此全部互通。
- 一次需求确定一个主应用，由其流程和 Agent 节点组织多 Agent 协作；平台路由层不临时拼装多个独立主应用。
- 主应用可显式复用其他已发布且有权调用的应用，绑定被调用版本并限制调用层数和次数；禁止循环依赖，不允许借子应用提升发起者的数据权限。
- 应用发布必须提交用途说明，包含能力范围、必要输入、预期输出和示例需求；可辅助生成，需创作者确认与审核。
- 个人长期记忆按使用者与应用隔离，明确请求或确认后保存；自动提取内容先作为候选。用户可查看、修改和删除个人记忆。
- 同会话最多一个活跃运行，后续普通任务排队；不同会话按配额并发，取消独立处理。
- 首期正式交付面向 Linux，使用 Docker Compose 部署，应用与脚本执行服务分离。Windows 开发端可以连接 Linux 执行服务。
- 脚本携带输入输出说明及依赖声明，调试/发布前准备固定环境；正式执行时不临时联网安装依赖。
- 完整首版包含基础组织知识库：资料上传、权限控制、检索与出处引用，与个人长期记忆分离。
- 完整首版节点集合为开始、结束、模型、Agent、脚本工具、调用应用、知识检索、条件分支、并行汇合、人工审批；首周只交付验收流程需要的子集。
- 对外发送、修改企业系统等受控高影响操作执行前需由有权限的发起者确认，批准与具体操作参数绑定；拒绝或过期终止本次运行。发布审核不代替运行审批，也不使使用者获得额外权限。
- 读取与纯计算有限重试，外部写入结果不明则暂停核对；恢复复用已确认完成的结果，保留失败及部分产物，不默认从头执行。
- 首版身份接入为管理员创建/邀请的本地账号，不开放公有自助注册；企业 OIDC/SSO 后续接入。
- 完整首版计划验收画像为 100 个用户、1000 个已发布应用、20 个并发执行的顶层运行，子任务和脚本另设配额；这些是待验证目标，不是实测能力或永久上限。
- 管理员授权主/备用模型，在有限重试后的可用性故障下进行兼容性受控的切换；记录原因及费用，不拼接两个模型的半段结果，预算耗尽停止。
- 首版缓存限于有明确身份、权限与来源版本的检索和确定性只读工具结果；个性化最终回答不跨用户共享，近似语义答案缓存后续评测。
- 用户指定 Go 后端、Vue Flow 画布（Vue 3）。已确认 Go 承担平台服务，Python worker 使用 LangGraph 执行工作流、DeepAgents 执行自主 Agent 节点。
- 运维后台默认展示脱敏运行元数据和操作审计；提示词、文件及结果正文受用户内容权限控制，诊断访问需显式授权并留痕。
- 用户可删除自己的会话、任务附件和个人记忆，使相关检索和缓存停止可用；审计保留必要元数据，备份按保留周期淘汰。具体清理时限与默认保留期在详细方案中提议并复核。
- 微调交付为 LlamaFactory 离线 LoRA 实验、独立评测及管理员模型登记，优先验证动态候选应用路由，首轮使用自建/公开数据。在线训练工作台、DPO 和强化学习后续按实际需求展开。
- 模型可用管理员批准的外部 API 或内网端点，应用展示数据目的地；私有部署不等于模型完全离线。
- 发布必须经过图/Schema/依赖/权限硬校验、最小应用测试与管理员审核，新模型需兼容评测。
- 完整首版提供 REST/SSE 和受限服务账号/API Key，高影响操作仍有人类审批负责人。

## 第一条验收样例

使用可公开复现的销售 CSV/Excel 数据，完成上传、脚本统计、Agent 分析以及可下载报告生成。加入格式错误与脚本执行失败案例。此样例用于验证平台能力，不是将平台限定为报表产品。

验收证据包括运行记录、独立统计真值、输出文件及失败处理；具体样本、指标和阈值见 WORKFLOW-SPEC、EVALUATION、OPERATIONS，均待实现验证。
