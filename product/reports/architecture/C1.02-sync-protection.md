## 用户故事

维护者运行既有同步命令，把有效来源完整发布到规格复制件与运行契约复制件，
包括正常文件删除；复制、核验或目录切换失败时保护或恢复上一份完整状态，
不得给半完成内容生成成功基线；危险布局与无效来源在触碰目标前拒绝。本报告
只覆盖本地工具验收，不是平台、模型、数据库或沙箱运行验收。

## 验收 seam 与方法

- 外部 seam：真实子进程执行 `python -X utf8 tools/sync_spec.py --source <临时来源>
  --dest <临时产品目录>`（必要时追加 `--check`），观察真实退出码与 stdout 诊断。
- 同一 module 定点入口：`sync.sync(source, dest)` / `sync.check(source, dest)`，
  用于在同一个真实临时目录上注入设计允许的私有文件操作失败并核对结果。
- 故障注入只使用 `shutil.copy2` / `_move` / `shutil.rmtree` / `_write_json` 等
  既有私有文件操作 seam；断言只读取两份受管复制件、`SYNC-MANIFEST.json` 基线、
  私有事务目录、受管范围外文件与命令退出状态，不新增生产故障注入入口。
- 所有内容事实来自真实临时目录中的实际文件字节；不使用内存文件系统。
- 注入式 CLI 场景（失败报告、提交后清理 warning）在真实子进程中 patch 私有 seam
  后调用 `sync.main([...])`，因此退出码、stdout 与 warning 文案都是命令层事实。
- 新增测试文件：`tests/tooling/test_sync_spec_c102_sync.py`（25 项）。

## 限制 / not_run

- **not_run**：真实物理断电、存储设备损坏或断电恢复。设计明确只验证可捕获失败与
  进程退出后的恢复；本票的失败注入是实际文件系统操作失败，不等于断电。
- **not_run**：远程/网络文件系统、跨卷、只读挂载或真实 OS ACL 权限拒绝。故障注入
  使用设计允许的私有文件操作 seam；这不是真实 ACL 证据。
- **not_run**：WSL/Linux 完整 pytest。本票只在 Windows 上运行；junction 分支已验证，
  POSIX symlink 分支沿用同一测试代码但本票未在 Linux 执行。历史 #137 只有 WSL
  标准库冒烟，不写成 Linux 套件通过。
- **not_run**：全产品 `pytest tests`、真实供应商、浏览器、数据库、沙箱或部署验收；
  按 brief 由最终整合票负责。
- 同一台机器上的恶意进程实时替换路径、在恢复期间抢占文件不是本工具的隔离承诺；
  本票只在测试进程内注入失败，不模拟持续对抗。
- Windows 文件锁在真实子进程中验证；删除锁文件抢占锁不在本票范围（历史已覆盖
  并发进程互斥）。
- 检查/同步允许创建私有 `.scratch/spec-sync/` 锁与事务状态（设计明确允许）；本报告
  断言的是两份受管复制件、基线、范围外文件与固定槽位，不声称操作不产生私有状态。
