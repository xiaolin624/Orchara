## 5. 新增/修改测试

### 5.1 Go seam 测试（`internal/presetexec/scheduler_regression_test.go`，5 个 top-level）

1. `TestGraphRunPublishesEachAttemptsSkipsOnce` — approval 先 park，第一 attempt 对 choose/
   left/right/join/end 不发布任何状态；resumed attempt 只发布 `right=["skipped"]` 一次，
   join/end 各运行一次，1 个 succeeded proposal + 1 个 exit。
2. `TestGraphRunCancellationDrainsStartedSiblings` — python 分支 A 阻塞在已启动 sandbox，
   分支 B 返回 `sandbox.ErrCancelled`；调度器必须等 A 停止后才确认 exit（`onConfirmExit` 钩子
   断言顺序），0 proposal、1 exit、join/end 各 1 skip。
3. `TestGraphRunCommitsOneProposalWhenTwoBranchesFailTogether` — 两个分支在屏障后同时失败，
   仍只有 1 个 failed proposal + 1 个 exit，join 不运行。
4. `TestGraphRunReusedOutputsNeverInventACompletedSkippedNode` — 为未激活分支伪造一个
   schema 合法的封存输出；该节点仍只有 `skipped`、无 node row，join envelope 仍为 skipped，
   已激活节点复用封存值（0 次 sandbox）。
5. `TestGraphRunMalformedSealedOutputIsNotTreatedAsCompleted` — 非对象封存输出不被视为已完成，
   节点真实重跑并发布新值。

既有测试未删除、未弱化：`graphrun_test.go`、`graphrun_parallel_test.go`、`agent_test.go`、
`callapp_test.go`、`callapp_context_test.go`、`nodeexec_test.go`、`approval_test.go`、
`modelnode_test.go`、`retrieve_test.go`、`cancel_exit_test.go`、`review2_test.go` 全部保持通过。

### 5.2 真实栈测试（`tests/f04b/test_c4_03_scheduler_regressions.py`，2 个）

1. `test_resumed_graph_attempt_publishes_the_skip_once_and_joins_once` — 真实 approval 决策
   + 恢复：waiting attempt 无 skip、恢复 attempt `right=(skipped, attempt 2)` 恰一次、join 1 行、
   两个 attempt 的 `reported_result` 为 `waiting_approval`/`succeeded`、最终输出含 skipped envelope。
