## 2. 共享 call_app 执行约定

```go
// 两种调度器都构造同一受约束输入（C4.01 + 本票新增固定版本事实）：
type nodeExecution struct {
    node          *manifestNode
    definition    *manifestDefinition
    inputs        []InputArtifact
    namespace     map[string]any   // 上游输出快照，启动时复制
    startNodeID   string
    scopeNodeIDs  []string         // sealed node-id 范围
    agentConfig   *agentConfig     // agent 专用（已证明配置）
    callAppConfig *callAppConfig   // call_app 专用：固定 VersionID
    sandbox       sandbox.Outcome
    report        *SandboxReport
}

// 节点只返回局部决定：
type nodeOutcome struct { kind /* succeeded|failed|cancelled|waiting */; output; code; message;
    sandbox; report; evidence; failureEvidence; startedForExit;
    proposal; outcomeName; fallbackCode; proposalRefusal; exitRefusal }
```

调度权威分工（与 C4.01 相同，本票把 call_app 接入）：

- **图**：`executeGraphCallApp` → `applyGraphNodeOutcome(attempt, outcome)` 只写
  `graphNodeAttempt`；`stopAndCommit` 执行 `cancel`、`drain`、`skipUnsettled`、
  `emitPendingSkips`，并由 `commitFailure/commitCancelled/commitWaiting` 唯一提交。
- **线性**：`runLinearCallAppNode` → `commitLinearNodeOutcome`，由线性调度器执行
  `skipRemaining`、failed proposal、cancel exit 或 waiting 提交。
- 节点自身只发布自己的 `pending/running/failed/succeeded` 观测事实；成功事实仍是“已登记
  node data artifact + node results”之后的最后一步。
- 等待时 proposal=`waiting_children`、checkpoint=`child:<child_run_id>`、error_code=
  `children_pending`、fallback=`child_spawn_failed`；exit 证据来自节点/调度器观察到的 sandbox 事实。
- 失败仍映射 child 的稳定平台码（`child_calls_exceeded`、`sandbox_unavailable` 等），
  无安全码时 `child_required_failed`；保留原 proposal/exit 拒绝文案。

## 7. 限制与 `not_run`（如实）

- **call_app 没有可观察的平台取消调用点**：`SpawnChild`/`ChildResult` 是唯一外部调用，父 run
  有取消意图时服务端拒绝为稳定码（`run_state_conflict`/`run_terminal`），不是取消信号；平台取消由
  finalizer 的 cancel 优先与 attempt-exit 权威处理（T114 语义未改）。因此本票以“等待时被调度器
  取消的 sibling”和 agent 的真实取消回归覆盖取消排空；未把 call_app 的 cancelled 分支写成已由真实
  平台取消触发。`nodeOutcomeCancelled` 的映射由两种调度器共用（C4.01 已验 agent 路径）。
- **全量 `pytest tests` not_run**：由最终整合票执行；本票只跑受影响真实模块与 Go 全包。
- **`go test -race` not_run**：本机 Go 工具链无 cgo（`-race requires cgo`），C4.01 已记录同一限制。
- **真实厂商模型 adapter / 浏览器 DOM**：不在本票范围（无页面改动）。
- 未跑 t082 跨应用交接模块：该模块不经过 call_app 节点执行路径（grep 无 `call_app`），
  本票改动不触及；t078/t080/t089 已覆盖子运行真实路径。
