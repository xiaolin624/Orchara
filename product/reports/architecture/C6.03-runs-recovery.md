## 4. 行为保持与有意的展示调整

- `finalizing` 仍是 phase、`cancelling` 仍是意图、`needs_reconciliation` 不改写为成功/失败；
  终态只由 committed Run 提交。
- 410 仍只按安全同源 Run 快照重建，绝不从 0 回放、绝不静默续传。
- 202 取消回执仍为“已接受取消意图”，不声称已停止/已撤销外部写。
- **有意调整**：`detail-note` 现在是 shared `view` 的一句话（例如 running 状态不再把
  lease 期限塞进 note）；真实 `started_at`/`lease_deadline` 仍由 `detail-lease` 行显示
  （`runLeaseText`），不丢失事实。`running` 的 note 由“服务器没有返回租约事实，本页
  不伪造进度”改为 shared 的“页面不伪造进度”，语义保持。
- 新增保守守卫：父 Run 快照为 `succeeded` 但 shared `parentMayShowSuccess=false`
  时，子运行状态行追加“本页不把该父 Run 显示为成功结论”。
