## 用户故事

维护者在同步进程异常退出后，能从现有检查命令识别未完成状态，并通过再次显式同步
恢复上次可识别的完整状态后继续；恢复本身再次中断、首次同步无旧版本或恢复证据异常，
都有可验证的失败/恢复结果。本报告只覆盖本地工具验收，不是平台、模型、数据库、
沙箱或断电持久性验收。

## 验收 seam 与方法

- 外部 seam：真实独立子进程执行 `python tools/sync_spec.py [--check] --source <临时来源>
  --dest <临时产品目录>`，观察真实退出码与 stdout 诊断。中断由**另一个**真实独立子进程在
  指定私有文件操作点调用 `os._exit(73)` 产生，不是 pytest 进程内的 ordinary exception。
- 四个切换位置：`_move` 第 1–4 次调用之后（规格旧树让位、规格新树安装、契约旧树让位、
  契约新树安装）。恢复中的再次退出用同一 seam 在恢复阶段第 1–N 次移动后发生。
- 其他真实进程退出点：待完成记录刚写入、首次切换之前；恢复提交后、当前 generation
  暂存期间（`shutil.copy2` 第一次复制后）；提交点（journal 移除）之后、清理旧槽期间。
- 同一 module 入口：`sync.check(source, dest)` / `sync.sync(source, dest)` 用于核对 CLI
  诊断与 module findings 一致，以及无效记录时 module 抛 `recovery_required`。
- 断言对象：两份受管复制件的实际文件字节、`SYNC-MANIFEST.json` 基线、私有
  `.scratch/spec-sync/transaction.json` 与固定槽位、受管范围外文件、命令退出码与诊断。
  不使用内存文件系统，不把私有 helper 的形状当结果。
- 新增测试文件：`tests/tooling/test_sync_spec_c103_interruption.py`（28 项）。

## 故障类别与原子性（AC8 的边界）

本票把三类失败分开记录，不互相代替：

- **进程退出（本票验证）**：真实子进程 `os._exit(73)`，操作系统释放进程锁；待完成记录
  保留在固定位置，下一次真实 `--check` 返回非零 `incomplete_sync`，显式 `sync` 先按记录
  和固定槽位恢复，再同步当前来源。恢复本身再次退出仍留下同一记录，可重复恢复。
- **普通 I/O 失败（C1.02/历史 #137 验证，本票只重跑回归）**：可捕获 `OSError` 在进程内
  触发回滚，待丢弃目录先移到 discard 槽，再恢复完整备份，然后移除记录。它与进程退出
  不同：进程退出时没有机会运行普通 exception 处理，只能依赖记录和下一次显式同步。
- **物理断电/设备故障（`not_run`，未验证）**：测试没有模拟掉电、写缓存丢失、设备损坏、
  远程/网络文件系统或跨卷 rename。两个受管目录由两次独立 rename 切换，**不具备一次
  文件系统原子提交**；journal 只把中间状态变成可检测、可从固定槽位重复恢复的状态，
  不承诺断电后的持久性。

## 限制 / not_run

- **not_run**：真实物理断电、写入缓存丢失、存储设备故障、断电恢复；见上节。
- **not_run**：远程/网络文件系统、跨卷、只读挂载、真实 OS ACL 权限拒绝或独占文件锁。
  本票的中断点使用设计允许的私有文件操作 seam（`_move`、`shutil.copy2`、`_write_json`、
  `shutil.rmtree`）放置真实进程退出，不新增生产故障注入入口。
- **not_run**：WSL/Linux 完整 pytest。本票只在 Windows 上实际运行；POSIX `fcntl` 锁分支
  未在本票重跑，历史只有 WSL 标准库冒烟，不写成 Linux 套件通过。
- **not_run**：全产品 `pytest tests`、真实供应商、浏览器、数据库、沙箱或部署验收；按 brief
  由最终整合票负责。
- 同一台机器上的恶意进程在恢复期间实时替换路径、抢占文件不是本工具的隔离承诺；本票只
  注入单次失败/退出，不模拟持续对抗。
