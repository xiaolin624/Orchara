服务账号（具名负责人）

服务账号是独立 principal：没有登录密码、没有角色，只能用带 scope 的 API key 访问， 并且每个动作仍要满足资源 ACL。负责人必须是已启用的人类用户；负责人被禁用后， 该账号的 key 立即失效（无需逐把撤销）。负责人只是治理归属，不会把 TA 的个人应用或记忆借给服务账号。
