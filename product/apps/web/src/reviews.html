        审核历史

        审核历史（谁在何时以何理由决定）不在 GET /api/v1/reviews/{id} 的返回里：本页只显示当前 state 与提交时冻结的快照，决策理由由服务端保存，页面不补造时间线（未提供）。

        审核决定（仅管理员）

        不可撤销

        批准会创建不可变版本并让应用可发布；拒绝会把创作者退回草稿编辑。两种决定都不可撤销，理由记录在审核历史里。

        hash 由页面在读取快照时自动填入；与冻结值不同会被服务端拒绝。

        拒绝时请写清缺项或风险；批准时也可记录依据。

        审核状态
        版本 ID

        批准后版本不可变；拒绝后创作者可以继续编辑草稿并重新提交。

        使用说明与技术详情

        管理员看到全部审核；创作者只看到自己提交或自己应用的审核。审核页展示冻结快照：用途卡、模型数据去向、 工具读写/联网、固定子版本、连接器策略和可信测试报告。审批只能针对冻结的同一 hash， 拒绝必须写明原因，拒绝后创作者回到草稿编辑。

        本页调用正式契约：GET /api/v1/reviews（cursor/limit）、GET /api/v1/reviews/{id}、 POST /api/v1/reviews/{id}/decision（管理员，Idempotency-Key 必填）。 未知或他人审核一律 404，页面不会枚举 id。
