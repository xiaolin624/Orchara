个人数据与删除进度（F11/T069）

删除在服务端是先 tombstone、后异步清理：请求返回 202 删除任务之前， 旧内容已经在同一个数据库事务里停止被下载、检索、缓存命中与恢复读取；受影响且仍可执行的 Run 会进入既有取消流程。物理副本由后续清理任务完成，本页如实显示任务状态与 remaining_scopes，不声称字节已删除。

本页只使用当前登录者自己的数据：他人的、未知的或格式错误的 id 都得到同一个 404。 删除任务返回的 id 是 deletion_job id，不是被删资源的 id。

      诊断授权（F11/T073）

      诊断授权只把指定运行中选中的对象正文开放给指定的另一位管理员，并限定用途与到期时间。 每次正文读取都会写审计（运行/尝试/操作关联），授权到期或撤销后立即失效。诊断授权 不包含训练同意，也不会把正文复制进审计或日志。
