    删除与影响范围

    破坏性操作，需确认
    • 立即停止访问：202 删除任务返回前，旧内容已在同一事务里 tombstone，下载、检索、缓存命中与恢复读取都停止。
    • 异步物理清理：对象存储、检索索引与备份删除账本由后台清理任务推进，页面用服务端返回的 remaining_scopes 显示剩余范围。
    • 不声称已删除：只要还有 remaining scopes，内容就保持不可读；失败的清理可以被后续重试，但绝不会让内容重新可见。
    • 先确认后提交：每次删除都会先显示确认与影响范围；返回的 id 是 deletion_job，不是被删资源的 id。

    按 id 删除文件（不可撤销）

    文件（artifact）的 id 出现在附件上传页或运行制品里。被发布/可恢复运行或应用配置引用的 配置 artifact 不会被删除，服务端返回 409 resource_in_use；页面会原样显示该错误码。

    诊断授权

    元数据授权，不含正文字段

    诊断授权只把指定运行中选中的对象正文开放给指定的另一位管理员，并限定用途与到期时间。 每次正文读取都会写审计（运行/尝试/操作关联），授权到期或撤销后立即失效。诊断授权 不包含训练同意，也不会把正文复制进审计或日志。

    对象列表默认不勾选：每个对象都要你明确选择才会进入授权范围，不会批量全选。

      最近一次删除

      删除任务，不是资源 id

      删除任务状态：待处理 / 执行中 / 已完成 / 失败。立即停止访问在 202 响应前已经生效； 异步物理清理与备份期限由后台清理任务与备份保留策略处理。只要还有 remaining scopes， 内容就保持不可读；失败的清理可以被后续重试，绝不会让内容重新可见。本页显示服务端返回的真实任务状态。

      手机端承诺记忆、文档、授权与删除状态的单列浏览；完整画布编辑不在手机端承诺（本页不提供画布编辑）。

      使用说明与技术详情

      删除在服务端是先 tombstone、后异步清理：请求返回 202 删除任务之前， 旧内容已经在同一个数据库事务里停止被下载、检索、缓存命中与恢复读取；受影响且仍可执行的 Run 会进入既有取消流程。物理副本由后续清理任务完成，本页如实显示任务状态与 remaining_scopes，不声称字节已删除。

      本页只使用当前登录者自己的数据：他人的、未知的或格式错误的 id 都得到同一个 404。 删除任务返回的 id 是 deletion_job id，不是被删资源的 id。

      两个读接口的数字就是上面的统计：GET /api/v1/memories 与每个知识库的 GET /knowledge-bases/{id}/documents（分页会被完整跟随），授权来自 GET /api/v1/diagnostic-grants。本页没有“导出”接口可调用，因此不显示导出按钮； 也没有删除历史列表接口，只显示最近一次删除任务。
