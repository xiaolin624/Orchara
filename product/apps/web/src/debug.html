私有调试（F02A 快照）

提交 POST /api/v1/applications/{id}/debug-runs 会把指定的草稿 revision 冻结成仅自己可见的执行快照，并创建一个 kind=debug 的 queued Run。调试不创建公共版本、 发布审核、平台 Request 或 Conversation；草稿随后如何修改都不会改变已经创建的 Run、快照和输入字节。 提交必须带 Idempotency-Key：同一 key 与同一请求会重放原来的 Run，不会创建第二个。 调试需要 creator 角色（管理员也需兼任），否则服务器返回 403 creator_role_required。 提交成功后本页用 GET /api/v1/runs/{id} 显示 Run 的 state / kind / revision / execution_snapshot_id。
