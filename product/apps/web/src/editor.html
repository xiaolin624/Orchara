应用编辑器（F02A 草稿）

用途卡（capability card）

新草稿的用途卡是空对象 {}。一旦填写，契约要求六项齐全，且 examples 至少 2 条；列表类字段每行一条。空草稿与已填用途卡的 表示差异是契约缺口，见 ADR 0004。

definition / layout

本票用文本域编辑 JSON（画布属 F04A）。非法 DSL 仍可保存，但不能调试或提交 （T025/T027 提供校验与调试入口）。layout 只影响视图，不改变执行内容。

保存冲突

服务器上的草稿已经更新。本页不会自动覆盖，也不会自动重载。请选择： 重载服务器版本会丢弃本地未保存修改；保留本地副本 会把当前表单内容下载为 JSON 文件，之后再决定如何合并。
