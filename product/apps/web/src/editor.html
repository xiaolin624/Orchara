应用编辑器（F04A 线性四节点画布）

画布主编辑器只允许 start → python → agent → end 的单条线性链；布局保存在独立的 layout 字段，不进入执行 definition，也不改变发布哈希。草稿来自 GET /api/v1/applications/{id}/draft，响应头 ETag 是本页保存时 If-Match 的值。保存成功后刷新页面会重新加载服务器上的草稿；若别人先保存了， 服务器返回 412，本页不会覆盖，而是让你重载服务器版本或 保留本地副本。保存需要 creator 角色（管理员也需兼任）， 否则服务器返回 403 creator_role_required。

画布配置

四类节点各一个：开始 / Python / Agent / 结束。只能连成单条线性链；非法连接会被拒绝并说明原因。 配置面板按节点类型显示字段、合法变量来源、工具/模型选择器与输出 Schema。校验调用 POST /api/v1/applications/{id}/validate，定位错误可点击跳转。 F07 的 call_app 节点不作为第五种画布节点伪装：它在下面的“子应用调用”面板中编辑， 写入同一份 definition，并沿用本页唯一的保存路径。

子应用调用（call_app，F07/T075）

只列出服务端按读权限过滤后的应用与已发布版本；固定版本不接受 latest。 选中版本后，输入/输出映射按该版本冻结的 definition Schema 生成。 撤销/不可见/循环/深度或次数超限等拒绝由 POST /validate 定位返回， 并在下方节点条上高亮对应节点。运行时执行子应用属于 T078，本页只声明并固化依赖。

输入映射（call_app.inputs）

每个子应用输入字段选择来源：应用输入（如 /source）、字面量 JSON 或上游节点输出 （如 python1#/report）。未映射的必填字段会被服务端定位为 io_mapping_missing_field；未声明的字段是 io_mapping_unknown_field； 类型不兼容是 io_mapping_type_mismatch。

输出声明（节点 output_schema）

只勾选希望向下游暴露的子应用输出。声明一个子应用没有的字段是 io_output_unknown_field，类型不兼容是 io_output_type_mismatch。 子应用只保证其冻结 Schema 声明的输出。

节点与定位错误

节点条：红色 = 服务端定位到该节点；虚线 = call_app 节点。点击节点可把它的固定版本与映射载回面板。

保存与校验需要 creator 角色，且只有该应用的所有者能写入（read 授权不是写授权）； 不满足时服务端返回 403，所以没有该角色时下面的编辑表单不显示（画布仍可查看）。

用途卡（capability card）

新草稿的用途卡是空对象 {}。一旦填写，契约要求六项齐全，且 examples 至少 2 条；列表类字段每行一条。空草稿与已填用途卡的 表示差异是契约缺口，见 ADR 0004。

JSON 视图（画布同步的 definition / layout，可折叠）

画布是主编辑器；文本域与画布双向同源。非法 DSL 仍可保存，但不能调试或提交 （校验按钮显示服务端定位错误）。layout 只影响视图，不改变执行内容。

保存冲突

服务器上的草稿已经更新。本页不会自动覆盖，也不会自动重载。请选择： 重载服务器版本会丢弃本地未保存修改；保留本地副本 会把当前表单内容下载为 JSON 文件，之后再决定如何合并。
