使用说明与技术详情

创作者提交一个已上传为 purpose=tool_source 的 zip 源包、输入/输出 Schema 与依赖锁，平台在隔离沙箱（gVisor/runsc、无网络、只读输入）中构建，成功后才写入 ready。构建成功不等于组织批准：只有管理员审核通过的工具才能进入共享执行； 作者自己的未批准 ready 工具只能用于私有调试。撤销后新执行与依赖校验都会被拒绝。

image_digest 在本票是内容包摘要（source + lock + SBOM 字节的 SHA-256），不是 OCI 镜像；F15A 才构建镜像。依赖锁需要本地 wheelhouse 的包在最小根文件系统上 会安全失败为 dependencies_unavailable，不会伪成功。撤销后再做依赖校验会返回 dependency_revoked，页面原样显示该错误码。

列表接口只返回七个字段（id、state、approved、manifest_sha256、image_digest、input_schema、 output_schema）：工具名称、版本号与构建时间不在列表返回中，本页不显示这三类信息； 构建日志/SBOM/审核记录来自非契约的 GET /api/v1/tools/{id}/build，只在展开时读取。
