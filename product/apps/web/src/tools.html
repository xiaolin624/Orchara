工具提交、隔离构建与审核（F05/T037）

创作者提交一个已上传为 purpose=tool_source 的 zip 源包、输入/输出 Schema 与依赖锁，平台在隔离沙箱（gVisor/runsc、无网络、只读输入）中构建，成功后才写入 ready。构建成功不等于组织批准：只有管理员审核通过的工具才能进入共享执行； 作者自己的未批准 ready 工具只能用于私有调试。撤销后新执行与依赖校验都会被拒绝。

image_digest 在本票是内容包摘要（source + lock + SBOM 字节的 SHA-256），不是 OCI 镜像；F15A 才构建镜像。依赖锁需要本地 wheelhouse 的包在最小根文件系统上 会安全失败为 dependencies_unavailable，不会伪成功。

提交工具源包

源包先通过 附件页 以 tool_source + application/zip 上传并完成准入，再把 artifact id 填在这里。

连接器版本当前恒为空：F06 负责连接器，服务器会拒绝非空列表而不是静默丢弃。
