附件上传（F05 上传准入）

选择文件后，本页调用 POST /api/v1/artifacts/uploads 预分配暂存 key和 封存 key，把字节 PUT 到短时签名 URL，再调用 POST /api/v1/artifacts/{id}/complete 提交 SHA-256。服务器随后在 artifact_finalize 后台任务里读取真实字节、校验 hash/大小、做格式准入，再写入私有封存对象。 状态依次为 uploading → scanning → ready，不通过的内容进入 quarantined。校验后即使签名暂存 URL 尚未过期、有人覆盖暂存对象，也不会改变已封存字节。 只有本人能读取自己的附件；管理员不会因此获得任意用户文件正文的读取权。

首版准入支持 text/plain、text/csv、application/json 与 .xlsx；拒绝宏、路径穿越、超解压/超条目、 类型不一致和非法 JSON/CSV/编码的内容。被隔离的附件不可下载，只显示安全的隔离原因代码。 上传成功时页面只在内存里计算 SHA-256，不把凭据或签名 URL 写入 URL 或浏览器存储。
