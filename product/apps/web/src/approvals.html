运行审批（F06/T050）

小屏支持查看待我审批、核对服务端封存的真实参数并明确批准或拒绝。 完整画布编辑（/editor、/debug）不承诺在手机上可用，请使用桌面浏览器。

审批只针对本 Run 的某一个受控操作。页面显示的是服务端封存的真实提案 （原始目标、方法/路径、规范化参数与哈希、数据去向、来源版本、过期时间），不是 worker 自报的文案。 批准不会赋予额外权限：恢复后的尝试仍会重新校验 attempt、manifest、策略、权限与预算， 并通过唯一的 authorized → dispatching CAS 最多派发一次。

诚实边界：取消/拒绝不会撤销已经发生的外部写入；本页不提供“撤销”。审批必须由 指定的人类审批人（F04A 为 Run 所有者）做出，管理员不是默认审批人；发布审核是另一个 聚合，不能代替运行审批。批准/拒绝按钮没有默认选择，只有你明确点击才会提交。
