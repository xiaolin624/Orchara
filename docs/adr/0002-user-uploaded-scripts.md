# 允许创作者上传脚本扩展能力

用户明确要求允许上传脚本，而非仅使用平台预置能力。该选择使执行隔离、资源限制、访问授权及脚本生命周期成为平台设计的一部分。普通业务人员仍通过可视化方式创作 Agent；脚本由谁编写、如何上传和发布、采用哪些语言与接口，将在后续访谈中决定。此决策没有授权脚本继承平台宿主、内网或全局凭据的权限。

后续确认：首版支持 Python，脚本作为声明结构化输入输出的工具，由平台统一管理调度。默认只能访问本次授权输入和独立工作目录；联网、企业系统及凭据需显式授权。执行时间、内存和输出大小需要上限，具体值和隔离实现尚未决定。

依赖交付已确认：脚本提交时附带输入输出说明与依赖声明，在调试或发布前准备固定环境，正式执行时不临时联网安装依赖。包准入、环境构建和故障反馈的实现细则另定。
